# How-to

This section covers common tasks for working with the charcoal CLI.

- [Install](./install.md) — Install charcoal on your system
- [Launch a Web IDE](./launch-web-ide.md) — Clone a repo and open it in browser VS Code
- [List Workspaces](./list-workspaces.md) — See all provisioned environments
- [Stop a Workspace](./stop-workspace.md) — Gracefully shut down a dev container
- [Update & Uninstall](./update.md) — Keep charcoal up to date or remove it
- [Contribute](./contribute.md) — Set up a development environment and submit changes

See the [CLI Overview](../cli/) for a high-level introduction to the command-line tool.
