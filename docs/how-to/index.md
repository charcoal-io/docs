- [List Workspaces](./list-workspaces.md) — See all provisioned environments
- [Stop a Workspace](./stop-workspace.md) — Gracefully shut down a dev container
- [Update & Uninstall](./update.md) — Keep Charcoal up to date or remove it
- [Contribute](./contribute.md) — Set up a development environment and submit changes
